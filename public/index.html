About WhoisDNS DevTools

          
A high-performance network engineering tool built for system administrators, security auditors, and DevOps engineers. Performs direct TCP port 43 WHOIS queries across all global TLDs (including .com, .org, .net, .id, and ccTLDs), resolves 15 DNS record types with TTL, audits email security (SPF, DMARC, DKIM, DNSSEC), and benchmarks Anycast propagation latency across 8 global resolvers.

        

        

          

            
            
Zero Slop / True WHOIS: Connects to authoritative registry port 43 servers with automatic IANA TLD referral discovery.

          

          

            
            
Dual Engine: Runs with native Node.js socket engine, falling back to client-side DoH when the backend is unreachable.

          

          

            
            
Email & Security Audits: Instant automated evaluation of SPF, DMARC, DKIM, DNSSEC, and CAA rules.
