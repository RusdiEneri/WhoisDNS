About WhoisDNS DevTools

          
A high-performance network engineering tool built for system administrators, security auditors, and DevOps engineers. Performs direct TCP port 43 WHOIS queries across all global TLDs (including .com, .org, .net, .id, and ccTLDs), resolves all 9 standard DNS record types with TTL, audits email security (SPF & DMARC), and benchmarks Anycast propagation latency.

        

        

          

            
            
Zero Slop / True WHOIS: Connects to authoritative registry port 43 servers with automatic IANA TLD referral discovery.

          

          

            
            
Dual Engine: Runs with native Node.js socket engine, with seamless client-side DoH fallback.

          

          

            
            
Email & Security Audits: Instant automated evaluation of SPF, DMARC, DNSSEC, and CAA rules.
